# Customer---Churn--Analysis-Dashboard
Interactive Power BI dashboard for analysis customer churn using IBM Telco Customer Churn Dataset .

## Dashboard Insights
- Total Customers
- Churn Rate Analysis
- Active vs Churn Customers
- Contract Type Analysis
- Internet Service Distribution
- Payment Method Analysis
- Monthly Charges by Tenure

## Tools Used
- Power BI
- DAX
- Data Visualization

## Dataset
IBM Telco Customer Churn Dataset

## Key Features
- Interactive Dashboard
- KPI Cards
- Filters & Slicers
- Business Insights
